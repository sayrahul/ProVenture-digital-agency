## 🚨 **Troubleshooting**

### **If Site Doesn't Load:**

1. **Clear browser cache:**
   - Ctrl + Shift + Delete
   - Clear cache and cookies
   - Try incognito mode

2. **Check DNS:**
   ```powershell
   ipconfig /flushdns
   nslookup proventure.in
   ```

3. **Wait for propagation:**
   - DNS can take 5-30 minutes
   - Sometimes up to 24 hours globally

4. **Check Vercel status:**
   - Visit Vercel Dashboard
   - Check deployment logs
   - Look for errors

### **If Contact Form Doesn't Work:**

1. **Check API endpoint:**
   - Visit: https://proventure.in/api/submit
   - Should return method not allowed (expected)

2. **Check Vercel logs:**
   - Vercel Dashboard → Functions
   - Check for errors

3. **Test locally:**
   - Run backend locally
   - Test form submission
